018 4Sum
===
`Array` `Two Pointers`
# Explanation
* 給定一個整數 array，回傳四個值相加等於 target。

# Approach 1: Two Pointers
* Sorting Array.
* Using recursion to solve the K-sum problem.
* Using two pointers to solve the two sum problem.

## Complexity
* Time: $O(n^3)$. $O(n^{K-1})$ for K-sum problem.
* Space: $O(n)$, for recursion. $O(K)$ for K-sum problem.

# Approach 2: Hash Set
* Sorting Array.
* Using recursion to solve the K-sum problem.
* Using hash set to solve the two sum problem.

## Complexity
* Time: $O(n^3)$. $O(n^{K-1})$ for K-sum problem.
* Space: $O(n)$, for recursion. $O(K)$ for K-sum problem.
